# AgentDeck 手机端 视觉与文案规格

> 交付对象：Codex　范围：只动 `apps/mobile`　基准机型：iPhone 17 Pro（402 × 874 pt，安全区上 62 下 34，可用高度 778 pt）
> 运行环境：Expo Go SDK 53 / RN 0.79.6　本文所有数值单位为 pt，颜色为 sRGB

产品要求（最高优先级）：「这个APP里面不要用句号，少用句号，不然太人机感了，然后你这个界面也太简单了，要有更复杂一些UI，就是可以好看帅气点，但是简单一点的是这种操作流程」

翻译成三条硬指标：

1. 界面里看不到「。」
2. 画面信息密度和质感上去（舰队总览、徽章、用量条、光晕、玻璃）
3. 操作步数一步不加：输入 → 开始

---

## 1 设计原则与气质

**一句话气质：深夜的调度塔台，安静、精密、一眼看清谁在线谁在干活**

| # | 原则 | 落地含义 |
|---|---|---|
| 1 | 画面复杂，操作简单 | 密度加在「看」的东西上（总览、设备卡、时间线），「点」的东西永远只有一个主按钮 |
| 2 | 只画真数据 | 没测到的余量画虚线并写「余量未知」，没连上的设备不出现，任何条形和数字都必须能追到协议字段 |
| 3 | 执行过程优先 | 事件流里推理、文件变更、回复占大头，系统状态和审阅缩到最瘦 |
| 4 | 光只给活的东西 | 光晕、脉冲只出现在在线设备、运行中任务、主按钮上，离线和未知一律哑光 |
| 5 | 说人话，不落句号 | 短句，用空格和换行断句，不用「。」，不卖萌，不放英文口号 |

| 令牌 | colors | start → end | 用途 |

状态色永远配文字，不允许只靠颜色表达状态

### 2.2 字体

系统字体（iOS 为 SF Pro + 苹方），不引入自定义字体。数字一律加 `fontVariant:['tabular-nums']`。等宽用 `Platform.select({ios:'Menlo',default:'monospace'})`

| 令牌 | 字号/行高 | 字重 | 字距 | 用途 |
|---|---|---|---|---|
| `display` | 28 / 34 | 700 | -0.5 | 配对页标题 |
| `title` | 20 / 26 | 700 | -0.3 | 主屏标题 |
| `stat` | 24 / 28 | 700 | -0.4 | 舰队总览数字 |
| `heading` | 16 / 22 | 600 | 0 | 卡片标题、任务标题 |
| `body` | 15 / 22 | 400 | 0 | 回复正文、输入 |
| `small` | 13 / 18 | 400 | 0 | 辅助说明、原因 |
| `caption` | 11 / 14 | 500 | 0.3 | 标签、分区名、时间 |
| `mono` | 12 / 17 | 400 | 0 | 路径、命令、终端输出 |

### 2.3 间距 圆角

- 间距刻度：`4 / 8 / 12 / 16 / 20 / 24`，页面左右边距 **16**（原 24，让出宽度给卡片），卡片间距 12，卡片内边距 12 或 16
- 圆角：`sm 8`（标签、小按钮）`md 12`（输入、时间线卡）`lg 16`（设备卡、原因条）`xl 22`（发令卡、底部坞）`pill 999`
- 最小点击区 44 × 44，视觉上小于 44 的用 `hitSlop` 补足

### 2.4 阴影 光晕

iOS 阴影只允许出现在下面三处，其余元素一律不加 `shadow*`

| 令牌 | 参数 | 用在 |
|---|---|---|
| `glowPrimary` | `shadowColor:#5CE1FF, opacity:0.45, radius:16, offset:(0,6)` | 主按钮（可用态） |
| `glowCard` | `shadowColor:#5CE1FF, opacity:0.18, radius:24, offset:(0,8)` | 发令卡一张 |
| `glowDot` | `shadowColor:当前状态色, opacity:0.9, radius:6, offset:(0,0)` | 在线脉冲点的实心核 |

有阴影的 View 必须有不透明背景色，并且自身不做动画（脉冲动画放在没有阴影的兄弟 View 上）

### 2.5 玻璃

| 类型 | 做法 | 允许数量 |
|---|---|---|
| **真玻璃** | `<BlurView intensity={40} tint="dark">` + 盖一层 `glassStrong` + 顶部 1pt `highlight` 线 + hairline `line` 描边 | 每屏最多 2 个：顶栏、底部坞 |
| **假玻璃** | 纯 View：`backgroundColor: glass` + hairline `line` 描边 + 顶部 1pt `highlight` 线（绝对定位，左右各缩进圆角值） | 不限，所有列表卡片用这个 |
| **渐变描边卡** | 外层 `LinearGradient(gradBorder)` padding 1，内层 `bgRaised` 不透明，圆角内层 = 外层 − 1 | 每屏最多 2 个：发令卡、原因条 |

Android 上 BlurView 降级为直接使用 `glassStrong`（`Platform.OS==='android'` 时不渲染 BlurView）

## 3 全局骨架

所有页面共用三层，从下到上：

### 3.1 背景层 `<Backdrop />`（绝对定位铺满，`pointerEvents="none"`）

| 元素 | 描述 | 动效 |
|---|---|---|
| 底色 | `bg` | 无 |
| 极光 | 一个 `LinearGradient(gradAurora)`，宽 100%，高 360，顶对齐 | opacity 0.6 ↔ 1.0，时长 6000ms，`Easing.inOut(Easing.sin)`，循环往返，`useNativeDriver:true` |
| 网格 | 一个容器内放 8 条竖线 + 9 条横线，线宽 `StyleSheet.hairlineWidth`，色 `rgba(92,225,255,0.06)`，格距 48，只铺屏幕上半 420 高，下缘盖一层 `gradFade` 高 160 | 静止 |
| 扫描线 | 一条宽 100% 高 1 的 `LinearGradient(['transparent','rgba(92,225,255,0.35)','transparent'])`（横向） | translateY 0 → 420，时长 9000ms，`Easing.linear`，循环，到底后 opacity 归零再回顶 |

事件流页不显示扫描线（避免干扰阅读），极光 opacity 固定 0.5 不动

开启系统「减弱动态效果」时（`AccessibilityInfo.isReduceMotionEnabled()`）所有循环动画停在静止态

### 3.2 顶栏（高 44，真玻璃，贴安全区顶）

- 删掉原来那条 2pt 青色横线
- 左：品牌标 = 一个 18 × 18 的青色渐变菱形（8 圆角方块旋转 45° 缩成 13 × 13，内部挖 5 × 5 的 `bg` 色小方块）+ 文字 `AgentDeck`（`heading`，`text` 色）间距 8。不再出现「/ 远程调度」
- 右：连接胶囊（配对页不显示），高 24，圆角 pill，内边距横 10
  - 已连接：`ok` 脉冲点 6 + 「已连接」，文字 `caption` `dim`，底 `rgba(61,220,151,0.10)`
  - 重连中：`warn` 点（opacity 1 ↔ 0.3，600ms，循环）+ 「重连中」，底 `rgba(245,193,92,0.10)`
- 事件流页左侧换成返回箭头，见 §7

### 3.3 提示条（错误）

顶栏正下方，页面左右 16，假玻璃卡，圆角 md，高度自适应最小 40，左侧 3pt `danger` 竖条，文字 `small` `text` 色，右侧 ✕（44 点击区）点了清空 `error`。出现时 translateY -8 → 0 + opacity 0 → 1，180ms，`Easing.out(Easing.cubic)`。保留 `accessibilityRole="alert"`

所有来自服务端的文字先过 `tidy()` 再显示，见 §8.1

### 3.4 通用组件规格（`ui.tsx`）

| 组件 | 规格 |
|---|---|
| `PrimaryButton` | 高 52，圆角 md+2=14，`gradPrimary` 填充，文字 16/600 色 `#04121A`，`glowPrimary`。按下 scale 0.97（Animated.spring，`speed:40, bounciness:0`）。禁用：改为纯色 `rgba(92,225,255,0.14)`，文字 `mute`，无光晕。忙碌：文字前放 3 个 4pt 点依次亮（每点 300ms，循环） |
| `GhostButton` | 高 44，圆角 md，底 `rgba(255,255,255,0.05)`，hairline `lineStrong`，文字 14/600 `accent`。`danger` 变体文字和描边用 `danger` |
| `TextLink` | 无底，文字 13/500 `dim`，带右侧 `›`，点击区 44 高 |
| `Input` | 底 `rgba(255,255,255,0.04)`，hairline `lineStrong`，圆角 md，内边距 14，字 `body`。聚焦：描边变 1pt `accent` + 底变 `accentSoft`（颜色切换不做动画） |
| `Pulse` | 状态点。核：6 × 6 实心圆 + `glowDot`。环：同心圆 6 × 6 无阴影，scale 1 → 2.6 + opacity 0.6 → 0，1800ms，`Easing.out(Easing.quad)`，循环。离线：核 `mute` 空心（1pt 描边），无环无光 |
| `AgentBadge` | 见 §5.3 |
| `QuotaBar` | 见 §5.4 |
| `Tag` | 高 20，圆角 sm-2=6，横内边距 6，`caption` 字。变体：`accent`（字 accent 底 accentSoft）`ok` `warn` `danger`（同理 12% 底）`mute`（字 dim 底 `rgba(255,255,255,0.06)`） |
| `SectionLabel` | `caption` `dim`，左侧 2 × 10 的 `accent` 小竖条，间距 6，右侧可带计数或 TextLink |

### 5.2 舰队总览

- 位置：顶栏下 12，左右 16，高 72，假玻璃，圆角 lg
- 三等分列，列间 hairline `line` 竖分隔（上下各缩进 16）
- 每列：上 `stat` 数字，下 `caption` `dim` 标签，垂直居中，左对齐内边距 14

| 列 | 数字来源（只许这样算） | 标签 | 视觉 |
|---|---|---|---|
| 设备在线 | `machines.filter(m=>m.online).length` / `machines.length`，分母用 `dim` 色 16 号 | 设备在线 | 在线数 > 0 时数字前放 `ok` 的 `Pulse` |
| AI 就绪 | 所有在线设备上 `selectable(machine,id)===true` 的 AI 个数 | AI 就绪 | 数字色 `accent` |
| 进行中 | `sessions` 里状态属于 `pending/starting/running/needs_approval/paused` 的个数 | 进行中 | > 0 时数字色 `accent`，数字下方一条 2pt 高 24 宽的 `accent` 短条，opacity 0.4 ↔ 1，1200ms 循环；有 `needs_approval` 时短条和数字改 `warn` |

状态：

- `machines.length===0`：三个数字都显示 `–`（`mute` 色），不写 0
- `!connected`：整条 opacity 0.5，停掉所有脉冲，右上角叠一个 `warn` Tag「状态待刷新」
- 数字变化时该数字 opacity 0.3 → 1，200ms，一次

### 5.3 AI 徽章 `AgentBadge`

圆角方块，底为该 AI 色 14% 透明度，hairline 描边为该 AI 色 40%，里面的图形全部用 View 拼，不用 emoji、不用图片、不用可能被 iOS 渲染成彩色 emoji 的字符（`✳ ⚡ ▶` 这类一律不用）

尺寸两档：`md` 22 × 22 圆角 7（设备卡、原因条）`sm` 16 × 16 圆角 5（任务行、时间线）

| AI | 显示名 | 色 | 图形（md 档尺寸，sm 档按 0.72 缩） |
|---|---|---|---|
| Claude | Claude Code | `claude #F2A26B` | 星芒：三根 2 × 12 圆头条，同心叠放，分别旋转 0° / 60° / 120° |
| Codex | Codex | `codex #7FA8FF` | 提示符：一个 `›`（用两根 2 × 6 条旋转 ±40° 拼成尖角）+ 右下一根 6 × 2 的下划线 |
| Grok | Grok | `grok #DCE3EE` | 斜杠环：10 × 10 圆环（1.5pt 描边）+ 一根 2 × 14 条旋转 35° 穿过 |
| Ollama | Ollama | `ollama #C7A6FF` | 本地芯：10 × 10 圆角 3 的方框（1.5pt 描边）+ 中心 4 × 4 实心圆角方块 |

## 8 文案对照表

### 8.1 规则

1. 新文案不出现「。」；中文句子末尾不放「.」；断句用空格或换行；「，」尽量少，一句里最多一个
2. 不用「请」开头的说明书句式，不用感叹号，不卖萌，不放英文口号
3. 省略号只用在进行态（`正在连接…`）
4. 所有来自服务端或 `client.ts` 的系统文字，显示前过 `tidy()`：

```ts
// presentation.ts
export function tidy(text:string):string {
  const mapped = serverCopy[text.trim()];            // 先查 8.6 的整句映射
  if (mapped) return mapped;
  return text
    .replace('；已知余量须大于 0，未知额度不编造','')
    .replace(/[。.]\s*$/u,'')                         // 去掉结尾句号
    .replace(/。\s*/gu,'  ')                          // 句中句号换成两个空格
    .trim();
}
```

`tidy()` 只用于：错误提示条、`decision.reason`、`session.status.reason`、`session.ended.reason/summary`、`error.message`、`approval.summary`。**不用于** `agent.message`、`agent.reasoning`、工具输入输出、文件内容

## 10 性能预算

| 项 | 上限 |
|---|---|
| 同屏 `BlurView` | 2 个（顶栏 + 底部坞）；列表项、设备卡、时间线卡一律假玻璃 |
| 同屏 `LinearGradient` | 8 个（背景 3 + 发令卡或原因条描边 1 + 主按钮 1 + 在线设备卡描边最多 3） |
| 同屏带 `shadow*` 的 View | 主按钮 1 + 发令卡 1 + 可见的在线脉冲核（最多 6 个，半径 6 的小阴影） |
| 同屏循环动画 | 12 个以内，全部 `useNativeDriver:true`，只动 `opacity` / `transform` |
| 背景层 | 固定 20 个以内的 View（17 条网格线 + 极光 + 扫描线 + 淡出），挂在根上不随页面重建 |
| JS 驱动动画 | 0（`LayoutAnimation` 除外） |

硬规则：

1. 带阴影的 View 不做动画，不随滚动重排；需要「呼吸光晕」时动的是垫在下面的无阴影色块
2. 不对宽或高超过 120 的 View 做循环 scale（背景极光只动 opacity）
3. `Pulse` 用一个共享的 `Animated.Value`（模块级单例循环）驱动所有在线点，不要每个点各起一个 loop
4. 离屏不动：设备卡和任务行的循环动画只给前 3 个可见项，其余静止；事件流页暂停主控制台的动画（页面卸载即可）
5. 时间线事件超过 40 组时把 `ScrollView` 换成 `FlatList`（`initialNumToRender:12` `windowSize:7` `removeClippedSubviews`），`groupEvents` 用 `useMemo` 依赖 `events` 和筛选模式
6. `now` 每秒 `setState` 只应触发审批坞倒计时重渲染：把倒计时拆成独立小组件自己起定时器，App 根上的 1 秒 `setNow` 删掉或下沉，避免每秒重渲整棵树
7. 流式回复只更新最后一张回复卡（卡片组件 `React.memo`，以组内最后一个 `seq` 为比较键）
8. 「减弱动态效果」开启时所有循环动画不启动
